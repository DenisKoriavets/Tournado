# Unified Error Format Specification — Tournado

> **Status:** Accepted  
> **Standard:** [RFC 7807 (Problem Details for HTTP APIs)](https://datatracker.ietf.org/doc/html/rfc7807) & Spring Boot `ProblemDetail`  
> **Traceability:** ADR-0003, ADR-0004, NFR-15, NFR-18

All client-facing REST endpoints in Tournado return errors using a single, strictly typed, predictable JSON structure. This format applies to authentication failures, domain validation errors, optimistic locking conflicts, and unexpected server failures.

---

## 1. Schema Definition

```json
{
  "type": "https://tournado.ua/errors/{error_code}",
  "title": "Short, human-readable summary of the problem type",
  "status": 400,
  "detail": "Human-readable explanation specific to this occurrence of the problem",
  "instance": "/api/v1/tournaments/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d/register",
  "code": "ROSTER_NOT_FULL",
  "timestamp": "2026-10-28T14:32:00.123456Z",
  "invalidParams": [
    {
      "name": "roster",
      "reason": "Team 'Navi Junior' has 4 players registered, but CS2 requires exactly 5 players."
    }
  ]
}
```

### Fields Specification

| Field | Type | Mandatory? | Description |
| :--- | :--- | :---: | :--- |
| `type` | `string (URI)` | **Yes** | A URI reference that identifies the problem type. Defaults to `about:blank` or `https://tournado.ua/errors/{code}`. |
| `title` | `string` | **Yes** | A short, human-readable summary of the problem type. It SHOULD NOT change from occurrence to occurrence. |
| `status` | `integer` | **Yes** | The HTTP status code generated by the origin server for this occurrence of the problem. |
| `detail` | `string` | **Yes** | A human-readable explanation specific to this occurrence of the problem (e.g. localized Ukrainian explanation). |
| `instance` | `string (URI)` | **Yes** | An absolute or relative URI reference that identifies the specific endpoint invocation (`request.getRequestURI()`). |
| `code` | `string (Enum)` | **Yes** | Machine-readable application error code from the Tournado Error Code Catalog (see §3 below). |
| `timestamp` | `string (ISO-8601)` | **Yes** | Precise UTC timestamp of the error event with millisecond/microsecond precision. |
| `invalidParams` | `array[object]` | No | Present only during request validation failures (`400 Bad Request`, `422 Unprocessable Entity`). Contains field-level details. |

### `invalidParams` Element Schema

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | `string` | The parameter/field name that failed validation (e.g., `slotLimit`, `steamId`, `scores[0]`). |
| `reason` | `string` | Explanation of why the validation rule failed. |

## 2. Standard HTTP Status Code Mapping

| HTTP Status | Semantic Meaning | Common Tournado Triggers |
| :---: | :--- | :--- |
| **`400 Bad Request`** | Malformed JSON, syntactic violations, unparseable UUID. | Invalid UUID format in path, unparseable request body. |
| **`401 Unauthorized`** | Missing, expired, or invalid authentication session. | Anonymous user attempting to create a team, access private endpoints. |
| **`403 Forbidden`** | Authenticated user lacks permission for this aggregate. | Non-captain trying to generate invite link, non-organizer closing dispute. |
| **`404 Not Found`** | Requested entity does not exist or was deleted. | Invalid tournament ID, non-existent team or invite token. |
| **`409 Conflict`** | Request violates unique constraint, state transition or lock. | Duplicate team name, duplicate registration, optimistic lock conflict (`@Version`). |
| **`422 Unprocessable Entity`** | Syntactically valid JSON, but violates business rule / invariant. | Submitting score before match starts, roster size mismatch, invalid time order. |
| **`500 Internal Server Error`**| Unhandled server exception or critical runtime failure. | Database connection failure, unhandled NullPointerException. |
| **`502 Bad Gateway`** | External integration failure. | Chess.com API unreachable or returning 5xx during background polling. |

## 3. Application Error Code Catalog (`code`)

### 3.1 Authentication & Profile (`AUTH_*`, `PROFILE_*`)

| Error Code | HTTP Status | Description |
| :--- | :---: | :--- |
| `AUTH_UNAUTHORIZED` | `401` | Authentication required to perform this action. |
| `AUTH_SESSION_EXPIRED` | `401` | JWT session token in HttpOnly cookie has expired. |
| `AUTH_FORBIDDEN` | `403` | User is authenticated but lacks required role (e.g. not tournament organizer). |
| `STEAM_AUTH_FAILED` | `401` | Verification of Steam OpenID response signature failed. |
| `EMAIL_MAGIC_LINK_EXPIRED` | `400` | The requested one-time login link has expired or has already been used. |
| `INVALID_GAME_IDENTIFIER` | `422` | Game identifier format check failed (Steam ID, Supercell tag, Chess username). |

### 3.2 Teams & Rosters (`TEAM_*`, `ROSTER_*`)

| Error Code | HTTP Status | Description |
| :--- | :---: | :--- |
| `TEAM_NOT_FOUND` | `404` | Specified team ID does not exist. |
| `TEAM_NAME_ALREADY_EXISTS` | `409` | A team with this name already exists within the specified discipline. |
| `TEAM_DISCIPLINE_IMMUTABLE` | `422` | Team discipline cannot be changed after creation. |
| `ROSTER_FULL` | `409` | Team roster has already reached the maximum allowed players for this game. |
| `ROSTER_NOT_FULL` | `422` | Team cannot register: roster player count is below the mandatory team size. |
| `PLAYER_ALREADY_IN_TEAM` | `409` | Player is already an active member of this team roster. |
| `INVITE_LINK_EXPIRED` | `400` | The team invite link has been deactivated or expired. |
| `ONLY_CAPTAIN_ALLOWED` | `403` | Action can only be performed by the registered team captain. |

### 3.3 Tournaments & Registrations (`TOURNAMENT_*`, `REG_*`)

| Error Code | HTTP Status | Description |
| :--- | :---: | :--- |
| `TOURNAMENT_NOT_FOUND` | `404` | Tournament with the given ID does not exist. |
| `INVALID_SCHEDULE_ORDER` | `422` | Schedule order violated: must be `registrationDeadline < checkInOpen < startTime`. |
| `SCHEDULE_TIME_IN_PAST` | `422` | Specified start/check-in/deadline time must be strictly in the future. |
| `INVALID_SLOT_LIMIT` | `422` | Slot limit must be one of {8, 16, 32}. |
| `REGISTRATION_CLOSED` | `409` | Registration deadline has passed or slots are full. |
| `ALREADY_REGISTERED` | `409` | Team is already registered for this tournament. |
| `MISSING_GAME_IDENTIFIER` | `422` | One or more roster members are missing the mandatory game identifier for this discipline. |
| `CHECKIN_NOT_OPEN` | `409` | Check-in window is not active yet. |
| `CHECKIN_EXPIRED` | `409` | Check-in window has closed. |
| `CHECKIN_ALREADY_CONFIRMED` | `409` | Captain has already confirmed check-in for this team. |
| `ROSTER_LOCKED` | `409` | Roster is locked; players cannot be added or removed. |

### 3.4 Match Room & Brackets (`MATCH_*`, `VETO_*`)

| Error Code | HTTP Status | Description |
| :--- | :---: | :--- |
| `MATCH_NOT_FOUND` | `404` | Specified match ID does not exist in bracket. |
| `MATCH_NOT_IN_PROGRESS` | `409` | Operation requires match to be in active playing state. |
| `READY_CHECK_CLOSED` | `409` | Ready check deadline (10 minutes) has already expired. |
| `NOT_YOUR_BAN_TURN` | `403` | Captain attempted to ban a map when it is the opposing team's turn. |
| `MAP_ALREADY_BANNED` | `409` | Map has already been banned or is not in the tournament map pool. |
| `BAN_PHASE_COMPLETED` | `409` | All veto steps completed; decider map has already been determined. |
| `SCORE_ALREADY_SUBMITTED` | `409` | Captain has already submitted a score for this match. |

### 3.5 Disputes & AI Verification (`DISPUTE_*`, `AI_*`)

| Error Code | HTTP Status | Description |
| :--- | :---: | :--- |
| `DISPUTE_ALREADY_OPEN` | `409` | An active open dispute already exists for this match. |
| `DISPUTE_NOT_ALLOWED` | `400` | Dispute can only be opened if score mismatch occurs or opponent failed to report. |
| `INVALID_SCREENSHOT_FORMAT` | `400` | Uploaded evidence must be PNG, JPEG, or WEBP. |
| `SCREENSHOT_TOO_LARGE` | `400` | Evidence file exceeds maximum size limit (10 MB). |
| `AI_SERVICE_UNAVAILABLE` | `502` | Internal AI service is unreachable or returned an error; fallback to manual arbitration. |

## 4. Concrete Error Payloads (Examples)

### Example 1: Field Validation Error (`400 Bad Request`)

```http
HTTP/1.1 400 Bad Request
Content-Type: application/problem+json

{
  "type": "https://tournado.ua/errors/VALIDATION_FAILED",
  "title": "Validation Failed",
  "status": 400,
  "detail": "Request body contains 2 validation constraint violations",
  "instance": "/api/v1/tournaments",
  "code": "VALIDATION_FAILED",
  "timestamp": "2026-10-28T14:35:10.512Z",
  "invalidParams": [
    {
      "name": "slotLimit",
      "reason": "Must be one of 8, 16, or 32"
    },
    {
      "name": "name",
      "reason": "Tournament name cannot be blank"
    }
  ]
}
```

### Example 2: Domain Business Rule Violation (`409 Conflict`)

```http
HTTP/1.1 409 Conflict
Content-Type: application/problem+json

{
  "type": "https://tournado.ua/errors/TEAM_NAME_ALREADY_EXISTS",
  "title": "Conflict",
  "status": 409,
  "detail": "A team with the name 'CyberKMA' already exists in the CS2 discipline.",
  "instance": "/api/v1/teams",
  "code": "TEAM_NAME_ALREADY_EXISTS",
  "timestamp": "2026-10-28T14:36:22.091Z"
}
```

### Example 3: Unauthorized Access (`401 Unauthorized`)

```http
HTTP/1.1 401 Unauthorized
Content-Type: application/problem+json

{
  "type": "https://tournado.ua/errors/AUTH_UNAUTHORIZED",
  "title": "Unauthorized",
  "status": 401,
  "detail": "Authentication via Steam or Email magic link is required to perform this action.",
  "instance": "/api/v1/teams",
  "code": "AUTH_UNAUTHORIZED",
  "timestamp": "2026-10-28T14:37:05.110Z"
}
```
